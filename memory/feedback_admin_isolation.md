---
name: Не ломать клиентскую часть при правках админки
description: При изменениях в админке (/admin) нельзя задевать стили и поведение клиентской части сайта
type: feedback
---

При работе над адаптивностью админки (и в целом над любыми её изменениями) клиентская (публичная) часть сайта не должна ломаться.

**Why:** Пользователь явно попросил "не сломай верстку клиентской части" при старте задачи по мобильной адаптации админки. Админка и клиентская часть делят общие SCSS-файлы (`app/assets/styles/main.scss`, `_utils.scss`, `_colors.scss`) и общий `ElementPlus` через `@element-plus/nuxt`.

**How to apply:**
- В общие SCSS-файлы (`main.scss`, `_utils.scss`, `_colors.scss`) только ДОБАВЛЯТЬ новые миксины/классы, не менять и не удалять существующие
- Не править глобальные CSS-переменные (`--color-*`) — только использовать
- Не трогать `layouts/default.vue` и `layouts/empty.vue`, компоненты вне `app/components/admin/`, страницы вне `app/pages/admin/`
- Все admin-стили держать `scoped` или префиксованными (`.admin-*`)
- `:deep()` для переопределения Element Plus использовать только внутри admin-scope, не глобально
